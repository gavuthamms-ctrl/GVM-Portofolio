# Gavutham MS — Portfolio Website

A modern, high-performance developer portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- **Dynamic Interactive Hero**: Dual-layer voxel art with custom mouse/touch spotlight reveal canvas and floating auto-pan animation.
- **Intro Splash Screen**: Cinematic staggered wine-red tile intro sequence.
- **Navigation Overlay**: Responsive glassmorphism menu panel with direct contacts and navigation links.
- **About Me**: Interactive counter statistics, profile picture with graceful fallback, and core philosophy.
- **Technical Skills**: Language showcase, areas of focus (AI & ML, Web Dev, Algorithm Design, Cybersecurity), and an infinite marquee ribbon.
- **Featured Projects**: Interactive cards with engineering details modal dialogs (AI Resume Analyser, Green Delivery Optimizer, Smart Resource Allocator).
- **Achievements & Hackathons**: Verified Microsoft & IBM certifications with direct credential verification links, and state/national hackathon highlights.
- **Resume Hub**: Quick overview metrics (CGPA, Deployed Projects, Recognition, LeetCode milestones) with PDF download and browser preview.
- **Contact Form**: Formspree integrated submission with in-app success state and email client fallback.

## Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Bundler & Dev Server**: Vite
- **Styling**: Tailwind CSS & Custom Design System Variables ("Vin Noir" palette)
- **Icons**: Font Awesome 6.5 & Lucide Icons

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```
